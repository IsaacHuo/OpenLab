# Contributors

The initial maintainer is [@IsaacHuo](https://github.com/IsaacHuo), the author of the repository's initial commit. Git history and GitHub's [contributors view](https://github.com/IsaacHuo/OpenLab/graphs/contributors) are the source of truth for code and documentation contributions.

Inspect local author records with:

```sh
git shortlog -sne --all
```

Credit non-code contributions in the relevant issue, PR, release note, or source document. Do not add people based on planned involvement. Third-party authors are credited separately in [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES.md).

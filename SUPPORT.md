# Support

Ask usage questions and discuss research workflows in [Discussions](https://github.com/IsaacHuo/OpenLab/discussions). Report a reproducible defect or request a feature or integration through the [issue chooser](https://github.com/IsaacHuo/OpenLab/issues/new/choose). English and Chinese are welcome.

Before reporting, check the [README status](README.md#current-status), [product specification](docs/product.md), and existing issues. v0.0.1 contains project governance and specifications; there is no research application to launch yet.

Provide the version or commit, environment, steps, and sanitized evidence. Security vulnerabilities use [private reporting](SECURITY.md). There is no paid support service or guaranteed response time.

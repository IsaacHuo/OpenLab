# OpenLab 视觉系统

这是[已确认设计](README.md)的目标规范，不是对现有绿色前端样式的记录。所有尺寸与色值由 [tokens.css](tokens.css)统一定义；以下说明其用途。

## 视觉原则

让聊天内容和可操作的研究成果成为视觉中心。先使用留白、对齐和字号分组，再使用细分隔线。仅在需要独立操作的输入框、消息、成果条目或弹出层上使用容器，不把每段内容装进卡片。

侧栏是安静的浅灰导航面；聊天和报告使用白色。黑色只强调主要操作、标题及当前标签，不增加品牌强调色、渐变、彩色状态点、玻璃效果或装饰性阴影。

## 配色与语义

所有灰阶必须满足 RGB 三个通道相等。组件引用语义令牌，不在业务 JSX 中散布色值。

| 语义令牌 | 使用位置 |
| --- | --- |
| `--ol-surface` | 页面、聊天、报告、输入框的白色底 |
| `--ol-surface-navigation` | 浅灰侧栏 |
| `--ol-surface-subtle` | 用户消息与轻微分组 |
| `--ol-surface-hover` / `--ol-surface-selected` | 悬停与当前选中项 |
| `--ol-text` / `--ol-text-secondary` | 正文与说明、时间、计数 |
| `--ol-border` / `--ol-border-control` | 面板分隔与控件边框 |
| `--ol-action` / `--ol-action-text` | 黑底白字主要按钮 |
| `--ol-focus` | 中性灰焦点轮廓 |

完成、执行中、失败、等待授权通过文字和图标区分。错误仍需可辨认，但不因此引入红色主题。普通文本及占位文字对比度至少为 4.5:1，大字与关键非文本边界至少为 3:1。

## 排版

使用一套产品无衬线字体栈：`Inter, "Segoe UI", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。复用现有字体资源或系统字体，不增加外部字体请求。

| 角色 | 字号令牌 | 字重 | 行高 |
| --- | --- | --- | --- |
| 产品字标 | `--ol-text-brand` | 600 | 1.2 |
| 对话结论与报告标题 | `--ol-text-title` | 600 | 1.35 |
| 报告章节标题 | `--ol-text-heading` | 600 | 1.4 |
| 聊天与报告正文 | `--ol-text-body` | 400 | 1.75 |
| 导航、按钮、菜单 | `--ol-text-control` | 400，选中时 500 | 1.5 |
| 版本、时间、计数 | `--ol-text-meta` | 400 | 1.5 |

正文采用 `16px`，控件采用 `14px`，辅助元数据采用 `12px`。禁止用 9–11px 小字承载正常操作或重要信息。长段落限制在约 `70ch` 内；项目和文件标题可截断，正文、错误、授权范围及研究局限必须换行。代码和哈希才使用等宽字体。

## 间距、形状与动效

- 使用令牌中的 4、8、12、16、24、32、40、48px 间距序列，不为每个组件另建尺度。
- 桌面面板内容内边距以 24px 为基准。头像与消息正文形成共同左对齐线；报告章节间距大于标题与正文间距。
- 小控件圆角 6px，普通控件与消息 8px，成果条目与弹出层 10px；聊天输入框独立使用 `--ol-composer-radius: 24px`。
- 输入框保持多行矩形，不变成胶囊。圆角不得裁切占位文字、附件、菜单、焦点轮廓或发送按钮。
- 页面与普通条目使用边框或留白，不使用阴影；弹出菜单、对话框可使用唯一的轻微浮层阴影。
- 悬停、展开使用 150ms 的颜色、透明度或位移动效。遵守 `prefers-reduced-motion`，不增加自动入场动画或模拟进度。

## 组件约束

| 组件 | 规范 |
| --- | --- |
| 主要按钮 | 黑底白字；桌面高度 40px；悬停略提亮；异步时显示状态并防重复提交 |
| 次级与图标按钮 | 透明或白底；使用统一的 Lucide 风格线性图标；图标按钮必须有可访问名称 |
| 选中导航项 | 浅灰底、深色文字；不使用彩色竖条；不要把每项做成独立卡片 |
| 模型、模式、技能、修订选择 | shadcn/ui Select 或 Popover/Command 等组合；长模型列表可搜索；不使用浏览器原生下拉菜单 |
| 研究成果标签 | 文本标签与简短计数；当前标签使用黑色下划线，计数来自真实记录 |
| 运行摘要 | 一个可折叠条目，包含实际状态、简短过程摘要和展开操作；不默认展示完整日志 |
| 成果条目 | 文档图标、标题、真实草稿或版本状态、打开操作；单层边框，不嵌套卡片 |
| 引用 | 紧凑可点击标记；黑白灰样式；键盘可操作；点击定位实际来源 |
| 对话框、抽屉 | 复用成熟组件的焦点管理、Esc 与关闭能力；仅在保护当前任务或窄屏空间不足时使用 |

焦点采用 2px 轮廓与 2px 外偏移。禁用状态保留必要的可读文字，不仅靠颜色暗示。移动端主要图标操作的点击区域至少为 44 × 44px。菜单必须通过 portal 等方式避免被滚动容器裁切。

## 复用与边界

shadcn/ui 负责 Button、Select、Popover、Command、Dialog、Sheet、Tabs、Collapsible、Tooltip 和 Resizable 等基础呈现；按实际需要引入，不一次安装整套组件。

AI Elements 优先用于 Prompt Input、Plan、Task、Tool、Sources 等适用呈现。它们只消费 OpenLab 现有状态和回调；不能为了复用外观而增加第二套会话存储或替换 AG-UI 协议。现有 assistant-ui 继续负责消息与流式内容。

当前前端采用 shadcn/ui 的 Radix 组合与 AI Elements Plan 的有限适配，样式直接使用本目录令牌，不为这些呈现另加 Tailwind 或 AI SDK。具体来源、修改范围、依赖与许可证见[组件来源](component-sources.md)。引入其他组件时继续记录依赖与许可证，使用兼容当前 React/Vite 的最小集合。

## 不接受的视觉偏移

- 把模型提供商、测试模型名称或通用 AI 星形图案当成产品身份。
- 恢复原前端的绿色、彩色 Tag、彩色焦点或渐变背景。
- 在输入框下方恢复标语、常驻帮助文案或固定高度的说明占位。
- 放大所有控件的圆角来替代输入框的独立圆角调整。
- 用常驻长表单、连续下拉菜单、运行历史或空白成果栏挤压聊天。
- 将参考图中的示例内容、来源数、完成状态和版本号写成正式页面常量。

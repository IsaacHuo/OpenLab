## [0.1.0-alpha.1] - 2026-10-25

### Added

- Static capability plugins for Markdown/LaTeX editing, recoverable drafts, immutable human revisions, comparison, BusyTeX compilation, PDF.js preview and portable v2 archives with v1 import compatibility.
- Long-term AI collaboration instructions, roadmap, status handoff and an index of accepted technical decisions, retaining the existing specifications and ADRs.
- Direct, confirmed metadata-tool execution without a model credential; a static runtime registry; real pinned skill/resource execution evidence and a first-preview acceptance matrix.

- Runnable bilingual React/assistant-ui workspace with official AG-UI adapter, projects/history, human decisions, live report revisions, source/step navigation, protected settings, material previews and keyboard-accessible drawers/divider.
- Native Chrome desktop/mobile acceptance and axe checks, a real browser DeepSeek/Crossref metadata research/export record, and native Windows credential module isolation checks.
- Authenticated loopback research API and OpenAPI definition, protected provider settings/capability tests, pinned inert skill installation, Crossref metadata/source tools, scoped public-page permissions and persisted AG-UI replay.
- Economics/English and humanities/Chinese live DeepSeek/Crossref metadata research, report revision and archive round-trip smoke tests.
- Initial TypeScript platform archive, generic single-agent Harness, supervised IPC worker and streaming model adapter, with confirmation, interaction validation, cancellation, restart reconciliation and immutable report archives.
- Native Windows core tests, strict type checking and an explicit opt-in DeepSeek streaming/tool-call smoke test.
- Research workspace specification covering conversation, execution state, live artifact revisions, evidence navigation, responsive layouts and application acceptance scenarios.
- Minimal OpenLab Harness specification and ADR 0002 selecting a self-developed first runtime, AG-UI at the Platform gateway and assistant-ui for conversation.

### Changed

- Make uppercase `PLAN.md` the visible execution-plan entry, retain historical ledgers, and map alpha data/permission gates to controlled and native-worker evidence.
- Apply the approved neutral workspace design and improve launch recovery, conversation/history navigation, frozen follow-up context, material selection and provider editing.
- Product, architecture, logging, architecture diagram and bilingual README now describe Platform-owned conversations, steps, human interactions and artifacts independently of runtime, model, tools and UI.
- OpenCode becomes an optional future adapter; ADR 0001 preserves the historical selection with a supersession notice.

### Fixed

- Keep comparison revision reads within the selected document; prepare pinned TeX components before browser CI and retain failed compiler diagnostics, screenshots and traces.
- Download the unchanged, hash-pinned Fandol font from a fixed CTAN mirror after candidate CI exposed a certificate failure through the rotating mirror endpoint; retain TLS verification.
- Merge concurrently completed material uploads into the latest conversation selection, preserving every selected file through refresh and run creation.
- Align development and acceptance documentation with implemented plugin capabilities, request limits and independent archive/database versions; retain the initial XeLaTeX CI failure separately from the subsequent passing checks.
- Preserve the selected report revision when navigating to its producing step, bind creation keys to limits/retry ancestry, reject invalid replay cursor indices, close interrupted AG-UI projections and retain TLS verification during isolated Windows Git installation.

### Preview boundary

- Source preview for Node.js 24 and a locally launched browser workspace; no installer, hosted deployment or npm package is provided.
- Windows user-scoped credential protection; Crossref metadata research; dated DeepSeek non-thinking compatibility. Metadata and model interpretation do not establish full-text access or scientific claim support.
- Static trusted plugins and supervised workers are not an untrusted-code sandbox. No arbitrary execution, multiple agents, team hosting or automatic process-loss recovery.
- TeX/font resources are downloaded separately (202,592,248 bytes), with checksums and resumable ranges; first preparation needs network access and curl. Cached offline compilation is tested. Missing packages fail while retaining the prior PDF; the Worker deadline is 120 seconds.
- Supervisor-Skills, local research data, credentials, installed local Skills/hooks, generated bundles and compiler/font binaries are excluded from source archives. Third-party licenses remain independent; see THIRD_PARTY_NOTICES.md.
- Validation includes 57 Node tests and 13 browser scenarios on the candidate, plus required Windows/Linux/browser CI. Historical live model/retrieval evidence remains dated; no new paid provider calls were made for this release preparation.

## [0.0.1] - 2026-10-24

### Added

- Apache-2.0 licensing, third-party attribution, contributor guidance, community conduct, support, and private security reporting policy.
- English and Chinese README and contribution guides; original vision, product specification, architecture, technical decisions, and logging specification.
- Code-generated vector product marks with mirrored shoulders, a circular bowl and a half-turn-symmetric wave, plus reproducible geometry and usage guidance.
- Bug, feature, and integration issue forms; PR template, ownership, labels, topics, and repository rules managed from versioned configuration.
- Cross-platform documentation and configuration checks, actionlint, Gitleaks, dependency updates, and PR module labeling.
- Maintainer-triggered releases with version, changelog, main-branch, CI, and duplicate-tag validation; protected version tags.

### Release boundary

This foundation release contains specifications and repository tooling. It does not contain a runnable research application, an installer, a verified Supervisor-Skills integration, or runtime security guarantees.
